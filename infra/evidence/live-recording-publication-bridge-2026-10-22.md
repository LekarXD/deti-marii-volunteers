## Authentication and control-plane proof

The test seeds a new fictitious staff identity, its grants and MFA factor, then
uses the real login challenge/verification and TOTP endpoints. Every subsequent
authoring/review command uses its actual session cookie and CSRF token through
the full application and HTTP ASGI transport. There are no principal dependency
overrides, skipped auth checks or special test auth endpoints.

It creates and publishes a separate baseline lesson through authoring routes,
then binds a recording project/take to an existing synthetic live webinar session.
The webinar/session rows and provider participant response are explicit local
fixtures; no external provider is contacted. The bind keeps the original room
identity. Actual policy/start endpoints approve the exact host audio source and
enqueue the recording job.

The completed capture/render row is an explicit media-worker output fixture,
separate from the capture-driver proof. The portable CI mode uses metadata-only
synthetic output. The real-file run imports verified bytes into this fixture and
labels its manifest `copied_native_live_mp4` / `publication_boundary_only`.
It does not claim this new QA take itself executed the native capture process.

## Review and publication proof

The owner downloads the exact bytes over the authenticated asset route and the
checksum matches; an unrelated anonymous registration is denied. The synthetic
webinar and session are closed before review, proving post-event processing stays
available. Missing recording approval and a wrong render hash are rejected.

After exact recording approval, attaching it preserves the original lesson text
and creates a new draft. Publication is rejected until the lesson is separately
reviewed; the old primary remains unchanged on that failure. Successful publication
creates exactly one recording-publication ledger row with the exact render hash,
changes the primary pointer and retains the old immutable lesson version. Revoking
the publisher's grant then denies replay of the old publish receipt.

Native capture provenance and this independent publication bridge are two
explicitly separated proofs. No real participant, device, external message,
provider credential, production service or shared development database was used.
