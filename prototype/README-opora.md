# Интерактивный прототип «Опора»

Рабочая версия от 21 октября 2026 года: 27 исходных экранов и 11 новых. Цвета, шрифты, карточки, кнопки и иконки взяты из исходного прототипа Claude. Архив оригинала сохранён в `materials/04-дизайн/прототип-до-фактуры/`.

## Открыть локально

Из корня репозитория:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Открыть [карту прототипа](http://127.0.0.1:4173/prototype/Main.dc.html) или [расписание](http://127.0.0.1:4173/prototype/Planning.dc.html).

React включён в `vendor/`; устанавливать зависимости не нужно. Inter подключается через Google Fonts, при отсутствии сети используется системный шрифт.

## Новые экраны

| Экран | Что можно проверить |
|---|---|
| `Needs.dc.html` | Поиск направлений, создание и изменение возможности, условий, подготовки, справки и способа согласования |
| `FundCatalog.dc.html` | Реальные направления помощи, фильтры, описание роли и отклик |
| `Participation.dc.html` | Отклик → решение координатора → подтверждение волонтёра → факт участия и часы; отзыв отклика |
| `FirstShift.dc.html` | Первый выход: встречающий, место, задачи, памятка, знакомство с группой, вопрос и отмена |
| `Roles.dc.html` | Справочник координатора: создание, изменение, архивирование и восстановление ролей; название, задачи и подготовка; роли доступны в расписании и возможностях |
| `Planning.dc.html` | Календарь без ограничения периода; месяц, неделя и список; создание, редактирование, перенос, отмена и возврат смены; изменение одной даты или серии; дни повторения, еженедельный, двухнедельный и месячный повтор; исключения; подбор команды и подтверждения; встроенный календарь даты и месяца; поиск роли и добавление из редактора |
| `VolunteerRecord.dc.html` | Договорённости, актуальность доступности, история контактов, следующий шаг и обсуждение первого выхода |
| `Reserve.dc.html` | Проверка старых контактов по одному; готовность помогать подтверждается вместе с доступностью |
| `Participants.dc.html` | Создание и изменение карточки участника, загрузка фотографии, интересы и памятка; просмотр без внутренних заметок координатора |
| `Groups.dc.html` | Создание и изменение группы, расписание, ведущий, волонтёры; добавление и исключение участников |
| `Group.dc.html` | Состав назначенной группы для волонтёра, фотографии и практические памятки |

В исходные экраны добавлены ссылки на новые разделы. В `Reflection.dc.html` появились вопросы после первого выхода и передача ответа в карточку волонтёра. Состояние новичка на `Home.dc.html` ведёт к памятке первого выхода.

Анкета, знакомство с кодексом и содержание онбординга остаются участком Фёдора. Исходные `Apply`, `ApplicationStatus` и учебные материалы не перерабатывались.

## Демонстрационные данные

Персонажи, группы, памятки и расписание демонстрационные. Настоящие фотографии и характеристики подопечных не импортировались.

Роли хранятся в отдельном справочнике. При выборе роли в возможности её задачи и подготовка копируются как начальные условия; затем их можно уточнить для конкретной возможности. Архивирование исключает роль из нового выбора, сохраняя существующие назначения. Изменения шаблона роли не переписывают условия назначенных занятий.

Изменения ролей, карточек участников, групп, расписания и новая рефлексия сохраняются в `sessionStorage` текущего браузера. Поэтому после изменения карточки можно перейти к группе и увидеть результат. На карте есть кнопка «Сбросить демо».

Уведомления, приглашения, решения о допуске и отметки часов имитируют работу продукта. Сервер, реальная отправка сообщений, аутентификация и защита данных на уровне API не реализованы. Просмотр карточки без внутренних заметок демонстрирует будущий интерфейс доступа; это не серверное разграничение прав.

## Исходники и проверки

Редактируемые части новых экранов лежат в `prototype-src/`: разметка, логика, общий CSS и данные. Сборка сохраняет формат `.dc.html` и раскладку `canvas.json`.

```sh
python3 scripts/build_prototype.py
python3 scripts/check_prototype.py
node scripts/check_prototype_logic.cjs
```

`support.js` — локальный вспомогательный рантайм для просмотра `.dc.html`. Работа проверена в браузере; публикация в исходный холст Claude Design не выполнялась.

Скриншоты и отчёт проверки — в `qa/` и `design-qa.md`.
