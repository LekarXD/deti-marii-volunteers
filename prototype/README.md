# Анкета, знакомство и собеседования в «Опоре»

> **Единый интерфейс — «Опора»:** `Apply.dc.html`, `Onboarding.dc.html`, `ApplicationStatus.dc.html`, `Candidates.dc.html`, `Interviews.dc.html` (см. [README-opora.md](README-opora.md)). Тексты общие — `content/`. Старая версия `app.js`/`styles.css` сохранена для истории, `index.html` её больше не запускает. Старые hash-ссылки перенаправляются в «Опору», сохраняя анкету, черновик и прогресс без перезаписи новых ответов.

Далее сохранено описание первой версии и источников. Актуальные экраны и проверки перечислены в README-opora. Вместо фиксированных слотов координатор редактирует доступность: разовые и еженедельные интервалы, длительность, перерывы и исключения. Анкеты и прогресс видны в «Кандидатах», встречи — в «Собеседованиях». Общий демонстрационный реестр `localStorage` (`opora-interviews-v1`) обновляется между вкладками; остальные изменения прототипа — в `sessionStorage`. Реальных сообщений, backend и авторизации здесь нет.

Рабочий кликабельный прототип пути нового волонтёра:

1. **Анкета на сайте фонда** — 4 шага с полоской прогресса: маски телефона и Telegram, имя и фамилия с автозаглавными и подсказкой про уменьшительные имена, конкретные роли внутри направлений, реальные площадки фонда, сетка «будни / суббота / воскресенье» ([почему поля такие](../materials/05-продукт/Анкета%20v2.md)).
2. **Письмо со ссылкой в кабинет** — заявка «проваливается» на платформу.
3. **Кабинет волонтёра** — путь из 5 этапов: заявка → знакомство с фондом → тест → встреча с координатором → первая смена.
4. **Онбординг** — 6 шагов: история, кому помогаем, **профиль для подбора** (физическая помощь, портфолио для фото и дизайна, помощь с дорогой), кодекс этики (четыре опоры, ситуации, полный текст), как общаться с участниками, первое занятие. В модулях есть места под видео: пока заглушки, ссылка на VK Видео, Rutube, YouTube или mp4 вставляется в `src`.
   Как с пользовательским соглашением: кнопка «Понятно, дальше» открывается, только когда модуль долистан до конца; сверху — полоска прочитанного. Пройденные модули открыты сразу.
5. **Тест** — 14 вопросов с пояснениями, проходной балл 11. Открывается после всех модулей.
6. **Запись на встречу с координатором** — открывается после теста.
7. **Профиль** — ответы анкеты, их можно изменить, прогресс при этом сохраняется.
8. **Рабочее место координатора** — новые волонтёры по статусам онбординга, флаги для подбора (физическая помощь, срок, доступность, справка), ответы анкеты и быстрые сообщения в канал, который выбрал волонтёр.

Сверху переключатель ролей, кнопка **«Крупный текст»** (для волонтёров 70+ и слабовидящих) и **«Сбросить демо»**.

## Как открыть

Нужен любой локальный сервер (по `file://` браузеры не всегда запускают скрипты):

```bash
cd prototype && python3 -m http.server 8000
```

Потом открыть http://localhost:8000. Сервера нет: всё хранится в `localStorage` браузера, у каждого своё демо.

## Как править тексты

Код трогать не нужно, все тексты — в `content/`:

| Файл | Что внутри |
|---|---|
| [`content/form.js`](content/form.js) | Анкета: шаги, поля, варианты, подсказки «зачем спрашиваем»; в `matching` — поля шага «Профиль для подбора» |
| [`content/onboarding.js`](content/onboarding.js) | Модули онбординга, тест, слоты встречи с координатором |
| [`content/demo.js`](content/demo.js) | Вымышленные кандидаты для экрана координатора |

Модули собираются из блоков: `lead`, `text`, `facts`, `timeline`, `cards`, `list`, `steps`, `phrases`, `situations`, `callout`, `pillars`, `check`, `more`, `video`. Форматы описаны в начале `onboarding.js`. Чтобы добавить модуль, достаточно дописать объект в `modules`: он сам появится в кабинете, в навигации и в подсчёте прогресса.

У модуля с `draft: true` в интерфейсе висит плашка «Черновик» с источником текста. Когда фонд пришлёт свои тексты, заменить содержимое и убрать `draft`.

- **Кодекс этики** — из [кодекса фонда](../materials/02-фонд/кодекс-этики/).
- **«Как общаться с участниками» и вопросы 11–14** — черновик команды по кодексу и практикам NSPCC, TBRI, PACE, National Autistic Society (подробности в [методичке тренажёра](../materials/04-дизайн/прототип-до-фактуры/research/trainer_best_practices.md)). **Заменить правилами коммуникации фонда.**
- **Слоты встречи и имя координатора** — демо.

## Связь с прототипом «Опора»

[«Опора»](../materials/04-дизайн/прототип-до-фактуры/README.md) делали до разговора с фондом, это холст с 27 экранами без логики. Здесь — рабочая версия первой части пути на реальной фактуре.

| «Опора» | Здесь | Что изменилось |
|---|---|---|
| `Apply` — «Стать волонтёром» | Анкета (`#/apply`) | За основу взята реальная анкета фонда, добавлены поля под подбор, согласие на ПДн и справка |
| `ApplicationStatus` — статус заявки, запись на собеседование | Кабинет (`#/home`) + встреча (`#/meet`) | Другой порядок: сначала онбординг на платформе, потом встреча. Рассказ о фонде, который сейчас занимает 30-минутные встречи, уходит в модули, а встреча — про подбор роли |
| `Academy`, `Lesson` — треки, уроки, сертификат | Онбординг (`#/learn/…`) | Один обязательный трек из 6 шагов вместо нескольких треков; тексты фонда и кодекс вместо выдуманных |
| `Simulator`, `Mentor` — тренажёр и ИИ-наставник | Модуль «Как общаться с участниками» и вопросы теста 11–14 | Пока статично: фразы и разбор ситуаций по той же методичке. ИИ-тренажёр — следующий шаг |
| `Profile` | Профиль (`#/profile`) | Ответы анкеты и шага «Профиль для подбора», их можно изменить |
| `Pipeline`, `Volunteers`, `CoordHome` | Координатор (`#/coord`) | Новые волонтёры по статусам онбординга, флаги подбора, сообщения в выбранный канал |
| `Catalog`, `Opportunity`, `Shifts`, `Schedule`, `Hours`, `Messages`, `Signals`, `Reports` | — | Ещё не сделано: это подбор, смены, календарь и учёт — следующая часть |
