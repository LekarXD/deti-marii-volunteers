# Прототип: анкета → кабинет → онбординг

Рабочий кликабельный прототип пути нового волонтёра:

1. **Анкета на сайте фонда** — новая версия на 4 шага, с проверками и условными полями ([почему поля такие](../materials/05-продукт/Анкета%20v2.md)).
2. **Письмо со ссылкой в кабинет** — заявка «проваливается» на платформу.
3. **Кабинет волонтёра** — путь из 5 этапов: заявка → знакомство с фондом → тест → встреча с координатором → первая смена.
4. **Онбординг** — 5 модулей: история, кому помогаем, кодекс этики, как общаться с участниками, первая смена.
5. **Тест** — 14 вопросов с пояснениями, проходной балл 11. Открывается после всех модулей.
6. **Запись на встречу с координатором** — открывается после теста.
7. **Профиль** — ответы анкеты, их можно изменить, прогресс при этом сохраняется.
8. **Рабочее место координатора** — новые волонтёры по статусам онбординга, флаги для подбора (физическая помощь, срок, доступность, справка), ответы анкеты и быстрые сообщения в канал, который выбрал волонтёр.

Сверху переключатель ролей, кнопка **«Крупный текст»** (для волонтёров 70+ и слабовидящих) и **«Сбросить демо»**.

## Как открыть

Нужен любой локальный сервер (по `file://` браузеры не всегда запускают скрипты):

```bash
cd prototype && python3 -m http.server 8000
```

Потом открыть http://localhost:8000. Сервера нет: всё хранится в `localStorage` браузера, у каждого своё демо.

## Как править тексты

Код трогать не нужно, все тексты — в `content/`:

| Файл | Что внутри |
|---|---|
| [`content/form.js`](content/form.js) | Анкета: шаги, поля, варианты, подсказки «зачем спрашиваем» |
| [`content/onboarding.js`](content/onboarding.js) | Модули онбординга, тест, слоты встречи с координатором |
| [`content/demo.js`](content/demo.js) | Вымышленные кандидаты для экрана координатора |

Модули собираются из блоков: `lead`, `text`, `facts`, `timeline`, `cards`, `list`, `steps`, `phrases`, `situations`, `callout`. Форматы описаны в начале `onboarding.js`. Чтобы добавить модуль, достаточно дописать объект в `modules`: он сам появится в кабинете, в навигации и в подсчёте прогресса.

У модуля с `draft: true` в интерфейсе висит плашка «Черновик» с источником текста. Когда фонд пришлёт свои тексты, заменить содержимое и убрать `draft`.

## Откуда тексты

- **История, кому помогаем, первая смена, вопросы теста 1–10** — из [онбординга Фёдора](../materials/04-дизайн/онбординг/) (сайт фонда, материалы АСИ).
- **Кодекс этики** — из [кодекса фонда](../materials/02-фонд/кодекс-этики/).
- **«Как общаться с участниками» и вопросы 11–14** — черновик команды по кодексу и практикам NSPCC, TBRI, PACE, National Autistic Society (подробности в [методичке тренажёра](../materials/04-дизайн/прототип-до-фактуры/research/trainer_best_practices.md)). **Заменить правилами коммуникации фонда.**
- **Слоты встречи и имя координатора** — демо.

## Чего здесь нет

Сервера, базы, реальных писем и сообщений, авторизации. Это следующий слой (зона Ильи): структура данных анкеты и прогресса в `app.js` подойдёт как черновик схемы.
