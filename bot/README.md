# Бот фонда «Дети Марии» — @detimarie_bot

Telegram-бот для волонтёров и координатора. Что он должен уметь — [описание функционала](../materials/05-продукт/Бот%20для%20волонтёров.md). Это первая рабочая версия: свои данные в SQLite, с прототипом «Опора» пока не связана.

## Что умеет

Все кнопки — под сообщениями бота. Внизу у поля ввода только кнопка «Меню» со списком команд: `/menu`, `/start`.

**Волонтёр и кандидат**
- `/start` — приветствие и ссылка на анкету. Регистрации в боте нет.
- Сообщения не копятся: раздел, открытый кнопкой, встаёт на место меню или прошлого раздела, под ним — кнопка «Меню» (`opora_bot/screen.py`). Приглашения, напоминания и файлы остаются в чате.
- «Войти по почте» — для тех, кто уже заполнил анкету на сайте: почта → код в письме через Unisender Go → вход. Код 6 цифр, 15 минут, 5 попыток, повтор раз в минуту, до 5 писем в час.
- Собеседование с координатором: запись приходит с сайта, бот после входа подтверждает дату и время. Напоминания за сутки и за 15 минут (за 15 минут — даже в тихие часы). Кнопка «Не смогу прийти» — отказ меньше чем за сутки сразу приходит координатору.
- Приглашения на занятия и мероприятия с кнопками «Приду», «Не смогу», «Подробнее».
- «Мои занятия» — ближайшие записи, часы, файл `.ics` для календаря телефона.
- «Материалы» — материалы к мероприятию и список группы с практическими советами. Видят только подтверждённые участники.
- Одно напоминание накануне в 18:00. После события — «Как прошло?» и часы.
- «Написать координатору» — вопрос уходит координатору, ответ приходит в бот.
- «Настройки» — новости фонда, итоги месяца, пауза.

**Координатор** (вход: `/coordinator <код>`, код в `.env`). Два режима: в «Режиме координатора» только его кнопки, «Режим волонтёра» показывает бот глазами волонтёра.
- **Новые уведомления** — лента того, что сделали волонтёры: вошёл в бот, записан на собеседование, согласился, отказался, не ответил 48 часов, отметил часы, написал о сложностях. Сверху «Нужно решить»: подтвердить согласившихся, итог прошедшей встречи, ответить на вопрос. У каждой записи — переход в карточку волонтёра.
- **Карточка волонтёра** — статус и собеседование, контакты, интересы и дни, сколько раз был и сколько часов, отказы, ближайшие записи, последний вопрос и сложности. Блок «Из анкеты» — заглушка до API сайта. Из карточки: итог встречи, «Написать в бот».
- **События** — 45 дней вперёд, «N из M»; в событии: позвать людей, карточки команды, Excel, отменить дату.
- **Рассылки** — кому (все допущенные, кандидаты, по роли, по свободному дню, кто давно не выходил) → новость или важное → текст или картинка с подписью (до 1024 символов) → предпросмотр с числом людей → отправка. История последних рассылок.
- **Новое событие**, **Выгрузки** — как раньше.
- **Отмена** — кнопка «Отмена» под каждым вопросом или слово «отмена» выходят из любого пошагового ввода: новое событие, рассылка, ответ, почта.
- Допуск к занятиям — только после собеседования: «Как прошло собеседование?» появляется в ленте через час после его начала.

**Сколько бот пишет.** Координатору сообщением приходят только вопросы волонтёров и отказы меньше чем за сутки, плюс одна сводка в 10:00 (что решить, где не хватает людей на неделе) — и только если есть что сообщить. Волонтёру — одно напоминание накануне встречи или занятия и вопрос «Как прошло?» после.

Тихие часы 22:00–9:00: необязательные сообщения ждут до утра. Изменения на сегодня и ответы координатора уходят сразу.

Демо-события — те же, что в расписании прототипа: Арт-суббота, Арт-лаборатория, подготовка продукции, экскурсия 22.10, открытие «Невидимого труда» 26.10. Участники группы Арт-субботы вымышленные.

## Запуск

```sh
cd bot
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env      # вписать BOT_TOKEN и COORDINATOR_CODE
.venv/bin/python -m opora_bot
```

Токен и код координатора лежат только в `bot/.env`, файл в git не попадает. База — `bot/data/bot.db`, тоже не в git.

Одновременно бот может работать только в одном месте: если запустить его на сервере, остановите все остальные копии.

### На сервере (Linux, systemd)

`/etc/systemd/system/detimarie-bot.service`:

```ini
[Unit]
Description=Deti Marii volunteer bot
After=network-online.target

[Service]
WorkingDirectory=/opt/deti-marii-volunteers/bot
ExecStart=/opt/deti-marii-volunteers/bot/.venv/bin/python -m opora_bot
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

```sh
sudo systemctl enable --now detimarie-bot
journalctl -u detimarie-bot -f
```

## Тестовый режим

`TEST_MODE=on` в `.env` добавляет в меню кнопку «Сбросить диалог (тест)» и команду `/reset`. Сброс стирает вход, собеседования, приглашения, часы и вопросы этого человека, и бот начинает с приветствия, как для нового. Вход координатора сохраняется. Работает в любой момент, даже посреди ввода кода. На рабочем сервере — `TEST_MODE=off`.

## Аватарка бота

`assets/avatar.svg` и `avatar.jpg` — логотип фонда с mariaschildren.ru, разложенный в две строки под круглую аватарку. Поставить или обновить:

```sh
curl "https://api.telegram.org/bot$BOT_TOKEN/setMyProfilePhoto" \
  -F 'photo={"type":"static","photo":"attach://avatar"}' -F "avatar=@assets/avatar.jpg;type=image/jpeg"
```

Или вручную в @BotFather: `/setuserpic`.

**Картинка на экране до «Старт».** `assets/description.jpg` (640×360) — логотип для экрана «Что умеет этот бот?». Через Bot API её не поставить, только в @BotFather: `/mybots` → бот → Edit Bot → Edit Description Picture → отправить файл.
