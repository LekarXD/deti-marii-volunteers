# Календарь мероприятий: карточка события

Прототип карточки события для календаря координатора. Модель данных, по которой он собран, — [Модель мероприятия](../../05-продукт/Модель%20мероприятия.md).

- [`event-card.html`](event-card.html) — открыть в браузере, работает без сервера. [Опубликованная версия](https://claude.ai/artifact/D7coGvBDpU4L3N1ayDp9dY).
- `event-card-art-sat.png`, `event-card-bazar-dark.png` — скриншоты: Арт-суббота (светлая тема) и Шерстяной Базар (тёмная).
- `planning-now.png` — как экран «Расписание» в «Опоре» выглядит сейчас, для сравнения.

## Что в карточке

Слева лента: впереди, черновики, прошли. Справа карточка выбранного события:

1. **Шапка** — вид (занятие, мастер-класс, мероприятие, выезд), формат, даты, площадка, кто организует, публичность и анонс, статус от черновика до «итоги внесены», ссылки на посты.
2. **Команда** — ответственный от фонда, ведущие и места для волонтёров по ролям и времени. У каждого человека свой статус: предложен ИИ → приглашён → согласился → подтверждён → пришёл.
3. **Программа** — части события, на которые нужны разные люди.
4. **Аудитория** — группы или «открытое», возраст, что важно знать команде.
5. **Материалы** — до, во время, после, и кто их видит.
6. **Подготовка** — задачи со сроками от даты события и отметкой «просрочено».
7. **Прошлые разы** — серия и похожие события, из них создаётся новое.

## Восемь событий

Шерстяной Базар (октябрь и черновик на декабрь), экскурсия «Люди решают», Арт-суббота, выставка «Невидимый труд», МК «В город приходит осень», день открытых дверей на Новинском, первый заезд арт-резиденции.

Даты, места, аудитория, программа и материалы взяты из постов фонда в ВК, у каждого факта номер поста. Волонтёры — вымышленные персонажи прототипа «Опора», они помечены «демо». Сколько волонтёров нужно — наша оценка, помечено «число — оценка». Сотрудники фонда названы по должности.

## Связка с расписанием

Рабочая версия карточки — [`prototype/Event.html`](../../../prototype/Event.html), она связана с расписанием `prototype/Planning.dc.html`.

- В расписании клик по событию → «Открыть карточку» → `Event.html#<событие>~<дата>`. У регулярного занятия открывается конкретная дата из серии.
- «Подобрать людей», «Редактировать», «Создать такое же» в карточке ведут обратно в расписание (`Planning.dc.html#<дата>~<событие>~people|edit|copy`), «← Расписание» — на тот же день.
- Карточка читает события и ответы волонтёров из `sessionStorage` вкладки (`schedule-v3`, `schedule-responses-v3`). Кого пригласили и подтвердили в расписании, сразу видно в карточке, и для регулярных занятий, и для разовых и многодневных событий: места основной роли строятся по дням, одинаковые дни склеиваются.
- Если у события нет своей карточки, она собирается из расписания и показывает, чего не хватает.
- В расписание добавлены события из карточки, цвета по видам и легенда, событие без времени и «0 волонтёров». Роли «Волонтёр мероприятий» и «Сопровождающий на выезде» пока есть только в расписании, в справочнике ролей их нет.

`event-card.html` в этой папке — статичный снимок дизайна.

## Чего нет

- В расписании у события одна роль, в карточке их может быть несколько: вторая и следующие роли пока живут только в карточке.
- В интерфейсе расписания осталось слово «смена».
