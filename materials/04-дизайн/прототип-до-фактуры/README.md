# Прототип «Опора» (сделан до фактуры)

Прототип делал друг команды **до** разговора с фондом, поэтому он опирается на предположения, а не на фактуру. Будем переделывать. Сохранён как источник идей.

- Оригинал: https://claude.ai/artifact/KeurJ9hsWHTx9g8ovz512u (холст Claude Design, смотреть там)
- Создан 2026-10-20
- `screens/` — исходники 27 экранов (`*.dc.html`) и раскладка холста (`canvas.json`). Это шаблоны для рантайма Claude Design, открыть их как обычные страницы не получится, но тексты и структуру читать можно.

## Экраны

**Старт и кандидат**
- `Main` — карта платформы и роли (кандидат Максим, волонтёр Анна, координатор Ольга)
- `Apply` — «Стать волонтёром»: путь ~3 недели (заявка → собеседование → документы → обучение → первое занятие), требования: 18+, справка о несудимости, раз в неделю
- `ApplicationStatus` — статус заявки, запись на собеседование с координатором

**Волонтёр**
- `Home` — главная: ближайшая смена, «Я приду / Не смогу», поиск замены среди тех, кто знает группу
- `Catalog` — возможности с ИИ-подбором и процентом совпадения
- `Opportunity` — карточка возможности, выбор даты старта
- `Schedule` — мои смены, список и календарь
- `Reflection` — «Как прошло занятие?»: текст или голос, часы засчитываются после подтверждения ведущей
- `Hours` — мой путь: часы, недели подряд, вехи, справка о часах, письмо от фонда
- `Messages` — сообщения, ИИ-сводка «пока тебя не было»
- `Profile` — профиль, ИИ предлагает обновить навыки по тексту «о себе»

**Академия**
- `Academy` — треки обучения, вебинары, сертификат
- `Lesson` — урок «Инклюзия: дети с особенностями развития»
- `Simulator` — тренажёр трудных ситуаций (в т.ч. тяжёлые темы, можно пройти с куратором)
- `Mentor` — ИИ-наставник «Что делать, если…», экстренный контакт психолога
- `Studio` — вебинар-супервизия с психологом

**Команда фонда**
- `CoordHome` — обзор координатора: что требует внимания (нехватка взрослых на смене, выгорание волонтёра, застрявший в обучении)
- `Pipeline` — заявки канбаном
- `Volunteers` — база волонтёров, активность по месяцам, паузы
- `Shifts` — смены на неделю и ИИ-подбор «кого позвать»
- `Signals` — сигналы из рефлексий (например, тревожные слова ребёнка) для психолога
- `Builder`, `Knowledge` — конструктор уроков и база знаний для ИИ-наставника (инструктор)
- `Scenarios` — сценарии тренажёра на проверку психологом
- `Reports` — отчёты для грантодателей (выгрузка в Word)
- `Admin` — роли и доступы (координатор, психолог, руководитель, инструктор)

**Телефон**
- `Phone` — мобильная версия для волонтёра

## Что расходится с фактурой

- В прототипе четыре внутренние роли (координатор, психолог, инструктор, руководитель). По словам фонда, изнутри пользоваться будет в основном **один координатор**.
- Названия, места и имена выдуманы («Мастерская на Дмитровке», «Подсолнухи», координатор Ольга). Реальные места — студия у м. Театральная / Новинский б-р 25, загородная мастерская (арт-субботы), ЦССВ «Никулино», «Радуга», «Сколково». Координатора зовут Алевтина.
- Нет учёта физических характеристик при подборе на смену (нехватка мужчин, помощь колясочникам) и версии для слабовидящих / пожилых волонтёров 70+.
- Нет ярмарок и маркетов, хотя это самый частый тип событий в ВК.
