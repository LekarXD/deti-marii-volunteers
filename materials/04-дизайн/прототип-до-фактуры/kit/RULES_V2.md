# Правила v2 — после ревью владельца (ВАЖНЕЕ всего в BRIEF.md)

Отзыв владельца на v1: «очень много мелкого текста и мелких деталей, глаз путается, непонятно куда смотреть.
Мелкий поясняющий технический текст — одно из самых худших, что выдаёт ИИ при дизайне, поставь запрет.
На белом всё сливается, не выразительно, непонятно, где акцент. Структурировать, убрать визуальный мусор, расставить акценты».

Образцы v2 (прочитай ЦЕЛИКОМ перед работой и делай так же): `project/Home.dc.html`, `project/Academy.dc.html`.
Новый кит: `kit/helmet.html` (v2) — вставь ЦЕЛИКОМ вместо старого helmet. Свои классы — в конец `<style>`, только нужные.

## Анатомия экрана
1. Шапка роли (как в образцах; активный пункт меню тёмный — это уже в ките).
2. Полоса состояний прототипа `.demo` с подписью «Прототип:» — только если у экрана есть состояния.
3. `h1` (40px). Без лида или одно короткое предложение — только если без него непонятно.
4. ОДИН акцентный блок `.card-hero` (сплошной жёлтый): главное на этом экране — крупный заголовок (44–52px),
   одна строка пояснения, ОДНА тёмная кнопка `.btn-primary` (+ максимум одна вторичная), справа можно `.hero-art`
   (крупная иконка в белом круге, см. образцы). Для тревожного главного (сигнал о ребёнке) вместо жёлтого —
   блок с фоном `var(--red-tint)` тех же размеров.
5. 2–3 раздела с `h2` (28px). Между разделами 56px (`.section`). Всё.

## ЗАПРЕЩЕНО (проверь себя по каждому пункту)
- Мелкий поясняющий/служебный текст: подписи под пунктами, сноски, «напомним за час…», «одобрил психолог…»,
  «12 материалов», «ведущий проверил», «источник: …», «собрано из…», «черновик — проверьте» под каждым блоком,
  повтор одного и того же счётчика в нескольких местах.
- Вторая строка под каждым пунктом списка. Допустимо только время/место/дата, коротко, одной строкой.
- Слово-статус на каждой строке («Пройден», «Сейчас», «Необязательный», «Ждёт»): статус — иконкой
  (галочка, замок, номер в кружке) или точкой; словом — только исключение (одна тревога на экран).
- Больше одного `.ai-tag` на раздел. ИИ-результат на экране — в одном `.ai-box`.
- Списки длиннее 4 строк — дальше кнопка «Показать все» (state).
- Больше одной `.btn-primary` в зоне видимости; больше двух кнопок в одном блоке.
- Теги/пилюли на каждой карточке; цветные плашки и подложки «для красоты»; рамки вокруг карточек.
- Текст меньше 15px. `.meta` (15px) — только для дат/времени/чисел.
- Больше 4 KPI в ряду. Больше 3 карточек в ряду.
- Формулы, «как считаем», методики, журналы, расшифровки — открытыми по умолчанию. Только по кнопке
  («Почему так», «Подробнее»), свёрнуто.
- Карточка в карточке. Белое на белом (кит: фон страницы тёплый серый, карточки белые без рамок).

## Можно и нужно
- Крупные цифры (`.big`/`.kpi-num`) как якорь; иконки `.art` в карточках (одна на карточку).
- Сетки по 2–3 крупные карточки вместо длинных списков.
- Пустые места — это нормально, не заполняй их.
- Взаимодействия сохраняй (переключатели, шаги, выбор, отправка), но ветки и состояния, которые добавляют шум,
  можно удалить. Данные и люди — только из BRIEF.md (даты уже по календарю 2026: «сегодня» — вт 20 октября,
  ближайшая суббота — 24 октября).
- Копирайт короче вдвое, чем в v1. Если фразу можно убрать без потери смысла — убери.
