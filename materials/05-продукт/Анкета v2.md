# Анкета волонтёра v2

Новая версия [текущей Яндекс-анкеты](../02-фонд/анкета-волонтёра/Анкета%20волонтёра.md) под задачу подбора. Рабочая форма — в прототипе: [`prototype/content/form.js`](../../prototype/content/form.js). Тексты меняются там, код трогать не нужно.

## Принцип

Анкета — это вход в платформу, а не полный профиль. Спрашиваем только то, что нужно, чтобы:
1. **подобрать** волонтёру занятия и смены: направления, навыки, аудитория, время, место;
2. **связаться** удобным каналом;
3. **обеспечить безопасность** участников: возраст, справка о несудимости, согласие на обработку данных.

Остальное (подробный график, предпочтения по группам, результаты обучения) волонтёр дополняет уже в личном кабинете. Анкета по-прежнему укладывается в ~10 минут.

## Что изменилось

| Поле | Было | Стало | Зачем |
|---|---|---|---|
| Дата рождения | строка | дата | проверка 18+; знаем возрастных волонтёров (70+) |
| Каналы связи | WhatsApp, Telegram, Max, почта, звонок | + **SMS** | координатор будет рассылать уведомления, нужен канал по умолчанию |
| **Район** | нет | список округов и регионов | подбор по удобству дороги; есть Ярославская обл. и Осетия |
| Направления | 9 общих пунктов | 9 пунктов, совпадающих с [ролями фонда](../02-фонд/роли-волонтёров/) | направление в анкете = роль в каталоге возможностей |
| **Навыки** | один свободный вопрос | теги + «другое» | сопоставление с занятиями (керамика, театр, фото…) без ручного разбора текста |
| Профессия | нет | текст | pro bono и специалисты (психолог, юрист) |
| **С кем комфортнее** | нет | дети 7–12 / подростки / взрослые | у фонда разные группы; это первое, что важно при подборе |
| Регулярность | 4 варианта | 4 варианта, конкретнее («каждую неделю», «пару раз в месяц») | |
| **Срок** | нет | до 3 мес / 3–6 / от полугода | фонду нужны постоянные волонтёры: доверие участников строится месяцами |
| **Когда удобно** | нет | сетка «будни/выходные × утро/день/вечер» | без этого невозможно звать на смены |
| **Куда удобно приезжать** | нет | студия в центре / загородная мастерская / ярмарки / онлайн | Арт-субботы — выезд за город, это отдельное решение |
| **Физическая помощь** | нет | по желанию: коляска, оборудование | запрос фонда (нехватка помощи с колясочниками); видит только координатор |
| **Доступность** | нет | по желанию: крупный шрифт, звонок, помощь с дорогой | волонтёры 70+, возможная версия для слабовидящих |
| Откуда узнали | свободный текст | список + «другое» | можно считать, какие каналы работают |
| **Справка о несудимости** | нет | готов / есть / обсудить | обязательна для работы с детьми; лучше знать заранее |
| **Согласие на обработку ПДн** | нет | обязательная галочка | 152-ФЗ; в текущей анкете его нет |
| Согласие на новости | нет | по желанию | законная база для рассылок |

У чувствительных полей (физическая помощь, доступность, срок) есть короткое «зачем спрашиваем». Так честнее, и люди охотнее отвечают.

## Сознательно не спрашиваем

- **Пол.** Фонду важна не гендерная принадлежность, а готовность к физической помощи. Её и спрашиваем напрямую.
- **Здоровье и медкнижку.** Не нужно на входе. Если понадобится для кулинарной мастерской, спросим на встрече.
- **Подробную мотивацию** — оставили одно необязательное поле.

## Уточнить у фонда

- Обязательна ли справка о несудимости для всех ролей или только для работы с детьми.
- Текст согласия на обработку ПДн и политика конфиденциальности фонда.
- Точные адреса площадок (студия, загородная мастерская) для подсказок о дороге.
