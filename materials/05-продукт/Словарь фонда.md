# Словарь фонда

Как говорит сам фонд. Собрано по 2 340 постам ВК за 2018–2026 ([выгрузка](../02-фонд/вк-группа/data/)), списку ролей и описаниям ролей. Числа — сколько постов употребляют слово.

## Главное: «смены» нет

Слово «смена» в волонтёрском смысле фонд не использует. За 8 лет — 12 упоминаний, и почти все про «смену обстановки» или **смену летней арт-резиденции** («участники второй смены», рядом — «заезд»). Волонтёр у фонда приходит **на занятие**, **на мастер-класс**, **на мероприятие** или едет **на выезд**.

| Говорим в продукте | Не говорим | Откуда |
|---|---|---|
| **занятие** — регулярное, в программе (Арт-лаборатория, Арт-суббота) | смена, дежурство | «занятие/занятия» — 798 постов |
| **мастер-класс**, **открытый мастер-класс** — разовое, часто ведут волонтёры | | 285 постов, растёт с 2024 |
| **мероприятие** — ярмарка, праздник, выставка, киноклуб | ивент | |
| **выезд**, для арт-резиденции — **заезд** или **смена** | | 34 / 7 |
| **участники** | подопечные, благополучатели | «участники» вытесняют «подопечных»: 2024–2026 — 215 против 14 |
| **ребята** — тёплое разговорное, о детях и взрослых | дети (о взрослых участниках) | самое частое слово в постах |
| **волонтёр** (пишут и через «е») | доброволец | 2 упоминания «добровольца» за 8 лет |
| **ведущий мастер-класса**, **педагог** | преподаватель, тренер | список ролей |
| **куратор** — сотрудник, который сопровождает конкретного участника | наставник (в программе наставничества — можно) | |
| **координатор волонтёров** | менеджер, HR | |
| **мастерские**, **студия**, **площадка** | центр, офис | «студия» — 891 упоминание |
| **социальные дома** (бывшие ПНИ), **ЦССВ**, **выпускники** интернатов | интернат для взрослых, детдомовцы | |
| **друзья фонда**, **команда фонда** | | |
