# Библиотека фонда

Материалы, которыми пользуется команда фонда: методички, исследования, правовые документы, памятки. Получены от фонда 2026-10-21. Выжимки для продукта — в [Выжимка библиотеки для онбординга](../../05-продукт/Выжимка%20библиотеки%20для%20онбординга.md).

Это чужие издания: храним для работы команды, в продукт переносим пересказ и выводы, а не тексты целиком.
