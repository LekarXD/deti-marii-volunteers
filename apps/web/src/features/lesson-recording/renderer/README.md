# Private renderer boundary — P18C, A2 checkpoint

This directory is separate from the normal application entry. `transport.ts` imports neutral errors only: no AppProviders, session bootstrap, cookie channel, analytics, service worker, local/session storage or device prompt. Shared Scene/CapturePlan/StudioStage remain the sole schema and layout engine.

`createRendererTransport(purposeTicket)` receives a ticket already handed over by the final verified private orchestration channel. **No URL, fragment, query-string or history-based credential transfer is implemented.** A1 owns the final launch channel, purpose signatures, scopes, revocation, generation fencing, renderer API DTOs and server journal. A4 owns the sole subscribe-only LiveKit adapter; no provider client is duplicated here.

This checkpoint includes the private coordinator in `runtime.ts`, using actual generated Renderer DTOs from the tested A1 source (`ca672fe`, visual lease `ed7f7b7`, sequence fence `e145f2f`; root SDK checkpoint `29f5048`). The endpoints are bootstrap/state/readiness/provider-grant and fixed private `/assets/{asset_id}`. No parallel response DTOs are introduced. The one-use bootstrap transport is closed after its response; a new client receives only `access_token` in memory for state, assets, readiness and provider renewal. It is not a recording success: actual capture-start is unavailable in the kernel.

Requests omit cookies and referrers, reject redirects, never put renderer credentials in URLs, bound deadlines/JSON/errors/image bytes, clear credentials and abort on rejection/close, and fence old responses. Asset downloads accept a UUID, never an arbitrary URL, and still require byte checksum verification before Stage. POST commands never retry automatically. Keep the same Idempotency-Key for a logical resend after uncertainty; a new key is a new command. Errors never expose HTTP request config or raw provider messages. No console logging of private responses or credentials. A separately scoped exception permits only LiveKit's short-lived least-privilege room JWT in configured-provider WSS signaling as required by its SDK; never persist or log that full URL.

Before readiness, the eventual entry must verify canonical scope/profile/revision, actual subscribed track/audio inventory, approved immutable asset/checksum projections, loaded fonts/images and onPlaying media. A1 decides whether/when provider capture starts after an acknowledged readiness receipt. Unknown privacy blocks capture; no raw fallback. No capture UI, audience controls, private chat, microphone/camera requests or publication belongs in the hidden renderer.

`frameFence.ts` validates canonical scene/plan scope and keeps an internal immutable stamp. A reused scene revision with changed pixels fails closed, cross-foundation/take/generation updates close the fence, and privacy revocation closes the fence even if scene pixels stay the same. A1 supplies an explicit monotonic renderer_state_version for policy/allowlist/asset authorization changes independently of scene_revision. The fence ignores older state versions, fails closed if the same state version changes payload, and accepts an approved changed plan only at a greater state version. Readiness ACKs bind that exact state version and actual `projection_hash`. Check `isCurrent(stamp)` after every async readiness acknowledgement before emitting a provider-ready signal. This is a browser race boundary, not the durable server journal or signature authority.

`assets.ts` verifies real PNG/JPEG/WebP bytes against the immutable scene SHA256 before creating a revocable BlobURL. Runtime uses the exact purpose-header download endpoint scoped to the access credential and asset. The helper bounds bytes, checks image magic/type, fences late async work to the active frame, and returns checksum proof mapped into the actual generated readiness DTO. Stage still checks decoded natural dimensions and fonts/media readiness. Leases are disposed on scope change/close. SVG/HTML and checksum failures cannot enter a capturable image surface.

`planHash.ts` remains an internal plan-only integrity helper with a Python stdlib golden over its integer/string/bool schema. Runtime verifies the full actual projection instead; the plan-only helper is not a wire receipt field or a replacement for ticket signature authorization. Preserve allowed_tracks array order when hashing and increment renderer_state_version if authorized plan bytes change.

The actual wire receipt uses `projectionHash.ts`: full RFC8785/JCS hash over `{scene,capture_plan,resolved_assets}`, including the approved asset inventory. Core `canonicalSerialize` matches ECMAScript number formatting and UTF-16 key ordering. Tests consume A1's actual numeric/Unicode/persisted-projection vectors in `apps/api/tests/fixtures/recording-jcs.json`; they also compare a content-asset scene with an independent Python RFC8785 hash. An integrity-valid unknown-policy projection remains blocked by the privacy fence. The plan-only helper is not a second wire receipt field.

`RendererView.tsx` remains a pure standalone view. `mount.ts` supplies `mountPrivateRenderer(element) → {start(oneUseTicket),close()}` for the eventual separate HTML entry. Mounting makes no request; the verified private orchestration channel must call start directly in memory. No ambient global, URL reader or automatic launcher is installed. This module imports StudioStage and the direct private HiddenCaptureController path; it renders no controls or regular application providers.

Runtime validates outer foundation/project/take/session/generation against canonical Scene/Plan, the monotonic state fence and full projection digest before connecting the one shared subscribe-only media adapter. Changed scene/policy state clears the old pixels before asynchronous asset/grant work. Reconnect obtains a fresh provider grant. API failures, revoked/unknown policy, asset/hash mismatch and stale scope fail closed. Readiness requires real Stage playing/font/image state, exact 1920×1080/DPR1 and actual observed tracks/checksum proofs. Native waiting/stalled/pause/emptied/ended/error events revoke media readiness; font-loading cycles revoke and recheck the original faces.

Each readiness observation/heartbeat gets a greater `readiness_sequence`. Ready leases last ten seconds and renew every three seconds; a false observation is sent immediately on visual loss. Local stamp/sequence checks discard stale ACKs. Close clears pixels/media, then retains the access credential only for one bounded best-effort false receipt at a greater sequence before destroying it. Server sequence CAS prevents a delayed older ready request from reopening that lease. No readiness ACK changes take state or starts elapsed recording time.

Validation: focused runtime/Stage/view/transport/hash/asset/fence suite passes, including delayed-ready close, revoked policy, changed frames, provider renewal and wrong viewport. An isolated production build includes the full private mount + LiveKit graph with `dependency-manifest.json` reporting no cookie transport, AppProviders, normal main/auth, analytics or service worker modules. It compiles 50 modules (32 nonvirtual); the LiveKit-containing entry is about 742 kB before gzip. This is dependency isolation proof, not capture/media acceptance. Private launch binding, actual browser asset/audio playback and recorded artifact verification remain with the integrated orchestration gate.
