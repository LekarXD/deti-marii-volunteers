# Bundled PDF fonts

DejaVu Sans Bold, version 2.37 (verified from embedded font names).
The regular face uses the shared `app.core.pdf_font.font_path()` packaged asset.
Copied unchanged from the existing local curator-bot `backend/static/fonts/` assets.

Upstream: https://github.com/dejavu-fonts/dejavu-fonts/tree/version_2_37
License: `LICENSE-DejaVu.txt`, downloaded from the official `version_2_37` tag.
The Bitstream Vera notice and the Arev notice are retained in that file.
No font is downloaded by the application at runtime.
